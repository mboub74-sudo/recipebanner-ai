# RecipeBanner AI

A zero-backend Pinterest recipe Pin studio. Static HTML/CSS/JavaScript. Upload a food image, create 3 editable Pin copy variants, render three 1000x1500 Pinterest images, download PNGs.

No AI API, database, or paid service required. All data stays in the browser. Text ideas are template-based, not generated by a language model. French localization is planned; current UI is English.

Deploy as static site: build command empty, output directory `.`.
